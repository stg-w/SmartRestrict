About Oracle Profile Storage

In compliance with the SmartRestrict Oracle schema specifications, profiles are saved in the USERS table and mapped to selected conditions via USER_RESTRICTIONS.

  • No plaintext passwords are ever requested or stored.
  • Saved profiles automatically highlight suitability when viewing any of the 852 Indian packaged products.
